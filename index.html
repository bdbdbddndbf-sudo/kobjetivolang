O mesmo botão em duas linguagens

Um contador de cliques que fica amarelo no décimo clique. Em JavaScript, antes de chegar à lógica, o aluno precisa entender seletores, funções de seta e três sinais de igual seguidos.

Em Objetivo, a lógica é a mesma (variável, evento e condição) e dá para ler em voz alta.

JavaScript 10 linhas

let cliques = 0;
const botao = document.querySelector("#somar");
const placar = document.querySelector("#placar");

botao.addEventListener("click", () => {
  cliques++;
  placar.textContent = cliques + " cliques";
  if (cliques === 10) {
    placar.style.color = "gold";
  }
});

Na sala de aula

Os conceitos são os de Python e JavaScript. Quem aprende com Objetivo chega nessas linguagens sabendo pensar como programador.

A mensagem de erro diz o que fazer

Quando o aluno erra, o editor mostra a linha, o trecho e uma sugestão. É assim que aparece na tela:

Erro na linha 7 Não conheço o comando "mostra". Você quis dizer "mostre"? mostra o aviso "Pronto!"

A página é desenhada com colchetes

O aluno organiza o site desenhando as áreas. A largura no desenho vira a largura na tela.

Perguntas de professores

Precisa instalar alguma coisa?

Não. Basta abrir o site no navegador. Funciona nos computadores do laboratório, em Chromebooks e em casa.

Isso é programação de verdade?

Sim. Variáveis, condições, repetições, listas, funções e eventos são os mesmos conceitos de Python e JavaScript. O que muda é que os comandos estão em português.

Para qual idade?

Dos 10 anos ao ensino médio. É simples para quem nunca programou, e o resultado é um site de verdade, então os mais velhos não acham infantil.

O professor precisa saber programar?

Não precisa ser especialista. O plano de aulas segue uma ordem, e as mensagens de erro explicam boa parte dos problemas direto para o aluno.

Quanto custa?

Os planos para escolas ainda estão sendo definidos com as primeiras escolas. Escreva para conversar.

Quer usar na sua escola?

Diga quantas turmas e quais anos. Combinamos uma demonstração para os professores.
